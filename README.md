# Tyria Ranger Paneli

Guild Wars 2 için Türkçe Ranger paneli. Hesabını, karakterini, günlük görevlerini ve kişisel hikâyeni Türkçe gösterir. Build sekmesinde açık dünya için Power Ranger rehberi var: 30. seviyeden 80'e adım adım, 80'de Soulbeast.

## Kullanım

1. Sayfayı aç: https://safaburakozkan.github.io/gw2-ranger-panel/
2. https://account.arena.net/applications adresinde **New Key**'e bas, bir isim ver, tüm kutuları işaretle.
3. Oluşan kodu panele yapıştır. Anahtar sadece senin tarayıcında saklanır ve sadece okuma izni verir. Panel onu yalnızca resmi GW2 API'sine (api.guildwars2.com) gönderir.

## Stack

Tek bir HTML dosyası. Kurulum yok, sunucu yok. Veriler `api.guildwars2.com` adresinden tarayıcıda çekilir.

## Build özeti

- Silahlar: Longbow (uzak) + Greatsword (yakın)
- Trait: Marksmanship, Skirmishing (45), Beastmastery (71)
- 80: Soulbeast (Path of Fire gerekir), Exotic Marauder set
